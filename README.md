# PaseÁgil · Trabajo final Healthtech

Prototipo navegable de PaseÁgil, una app para agilizar el pase de sala: tablero de las últimas 24 horas, registro del pase, pedidos en un toque, indicación de cirugía con ayuno automático y vista de enfermería.

Grupo 6 · MBA Universidad de San Andrés: Luciano Rossi, Sebastian Heredia, Verónica Diz y Gabriela Zenarruza.

Todos los pacientes y valores son ficticios. Es un único archivo estático (`index.html`), sin dependencias ni servidor.
